\# ORSPEX PDF Compressor



Free, private, browser-based PDF compressor. No uploads. No signup. No watermark.



\## 🌐 Live



\- \*\*Primary:\*\* https://orspex-pdf-compressor.vercel.app/

\- \*\*Mirror:\*\* https://orpexexitus-maker.github.io/orspex-pdf-compressor/



\## ✨ Features



\- 100% client-side compression with \[pdf-lib](https://pdf-lib.js.org/)

\- Zero server uploads — your PDF never leaves the browser

\- Strips metadata (title, author, subject, keywords, producer, creator)

\- Re-saves with object streams for smaller file size

\- Works on Windows, macOS, Linux, Chromebook, iPad

\- No install, no signup, no limits
